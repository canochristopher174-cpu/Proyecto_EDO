# Proyecto Final

Este repositorio contiene todos los archivos correspondientes al desarrollo del proyecto. Con el fin de facilitar la revisión y evaluación, cada componente se encuentra organizado de manera independiente y acompañado de los archivos necesarios para su ejecución y análisis.

## Contenido del repositorio

* Archivos fuente del proyecto.
* Scripts desarrollados en Python (.py).
* Scripts desarrollados en JavaScript (.js).
* Archivo comprimido (.rar) con una versión completa del proyecto.
* Declaración sobre el uso de inteligencia artificial durante el desarrollo.

Este repositorio tiene como propósito servir como respaldo y entrega final del proyecto, incluyendo todos los recursos necesarios para su revisión y evaluación.
